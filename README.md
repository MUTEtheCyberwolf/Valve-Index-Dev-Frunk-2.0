The Valve Index DEV Frunk 2.0 is an enhanced modification for the Valve Index VR headset, designed to provide developers and users with expanded mounting options for various accessories. Building upon the original DEV Frunk 1.0, this version offers improved features to facilitate the integration of devices such as eye-tracking modules, facial trackers, and additional cooling solutions.

# Key Features:

  ## Enhanced Mounting System: 
  The DEV Frunk 2.0 introduces a more user-friendly design, featuring multiple M3 mounting points that allow for secure attachment of various accessories without causing damage to the headset.

  ## Improved Accessibility: 
  The modification is designed to be beginner-friendly, enabling users to easily customize their headset with additional devices.

  ## Increased Durability:
  DF2.0 now offers a 30% higher resistance to impacts than DF1.0.

  ## Reversible Modification: 
  All changes made using the DEV Frunk 2.0 are reversible, ensuring that the original state of the headset can be restored if needed.

  ## Support for FaceFocusVR Mainboard:
  The DF2.0 was mainly designed to house the FaceFocusVR Mainboard combining Eyetracking and Facetracking into a single PCB. (Cable routing now goes THROUGH the Index)
